# Professional Portfolio Website — Week 1 Task 1

## Project
A responsive multi-page personal portfolio website built for the Web Development Internship Week 1 assignment.

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Git & GitHub

## Pages
- Home
- About
- Projects
- Contact

## Features
- Responsive desktop/tablet/mobile layout
- Semantic HTML structure
- Dark/light mode toggle
- Mobile navigation
- Smooth scrolling
- Scroll reveal animations
- Project category filtering
- Resume download button
- Accessible form labels and focus states
- Responsive contact form with HTML validation
- Reusable CSS classes

## Folder Structure
